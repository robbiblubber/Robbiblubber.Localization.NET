Paramètres

Outils › Paramètres... (Ctrl+Alt+S) ouvre les paramètres de l'éditeur.

Langue de l'éditeur

Sous Environnement › Langues, choisissez la Langue de l'interface. Toutes les fenêtres changent aussitôt de langue, ce qui vous permet de voir le résultat immédiatement. OK conserve la nouvelle langue ; Annuler ou Échap rétablit la précédente. L'éditeur mémorise votre choix.

L'éditeur est fourni en English, Deutsch, Français et Bahasa Indonesia.

Ajouter une langue à l'éditeur

L'éditeur est localisé à l'aide de ses propres fichiers : vous pouvez donc le traduire vous-même.

  1. Créez une définition de langue pour la langue, par exemple es.locale.
  2. Ouvrez la table anglaise de l'éditeur, led.en.ltab, dans le dossier locale à côté de led.exe, enregistrez-la sous led.es.ltab, définissez sa Langue sur es et traduisez les textes.
  3. Placez les deux fichiers dans le dossier locale à côté de led.exe et redémarrez l'éditeur.

La nouvelle langue apparaît alors dans les paramètres. Les textes absents de votre table s'affichent en anglais.

Apparence

Sous Environnement › Apparence, choisissez le Thème de l'éditeur. Comme pour la langue, toutes les fenêtres changent aussitôt ; OK conserve le thème, Annuler rétablit le précédent.

ThèmeCouleurs
AutomatiqueClair ou sombre, selon le réglage des applications dans les paramètres de Windows ; en contraste élevé, les couleurs de Windows
SystèmeLes couleurs de Windows, comme sans thème
ClairCouleurs claires
SombreCouleurs sombres

Vos propres thèmes suivent les thèmes intégrés dans la liste.

Vos propres thèmes

Le lien Personnaliser... à côté de la liste ouvre l'éditeur de thèmes. Créez un thème avec Nouveau ou Copier. Chaque thème est Basé sur un autre thème et ne modifie que les couleurs que vous définissez : sélectionnez une couleur et cliquez sur Modifier... ; Réinitialiser la couleur reprend la couleur du thème de base. L'aperçu montre aussitôt le résultat. Importer... et Exporter... échangent des thèmes sous forme de fichiers .theme, Supprimer efface un thème. Les thèmes intégrés ne peuvent pas être modifiés.

Si vous fermez l'éditeur de thèmes avec OK, le thème choisi devient le thème de l'éditeur et vos thèmes sont enregistrés aussitôt, même si vous fermez ensuite les paramètres avec Annuler.

Vos thèmes sont conservés dans %APPDATA%\robbiblubber\themes. Les autres applications de robbiblubber.org qui prennent en charge les thèmes utilisent le même dossier : un thème créé ici y est également disponible, et inversement. Chaque application mémorise son propre choix de thème.

Paramètres enregistrés

L'éditeur conserve ses paramètres pour chaque utilisateur dans %LOCALAPPDATA%\robbiblubber.org\led :

FichierContenu
led.settingsLangue de l'éditeur, historique et options de recherche
led.recentLa liste des fichiers récents
led.layoutPositions et tailles des fenêtres, largeurs des colonnes des tables
led.themesLe thème de l'éditeur

Si une fenêtre s'ouvre à un endroit inattendu, fermez l'éditeur et supprimez led.layout. Toutes les fenêtres s'ouvrent alors de nouveau à leur position par défaut.
