Outils

Le menu Outils vous aide à travailler sur les textes longs et à garder plusieurs tables à jour les unes par rapport aux autres. Les outils sont disponibles dans les fenêtres des tables de langue.

Éditeur de texte

L'éditeur de texte affiche un texte avec de vrais sauts de ligne et de vraies tabulations, ce qui facilite la lecture et l'écriture des textes longs. Pour l'ouvrir, utilisez :

  • Outils › Éditeur de texte... ou Ctrl+E,
  • un double-clic sur une cellule de texte, ou
  • Éditeur de texte... dans le menu contextuel de la table.

L'éditeur modifie toujours le texte de la ligne active, même si c'est la cellule du symbole qui est sélectionnée ; son titre affiche le symbole.

ToucheEffet
EntréeNouvelle ligne
TabTabulation
Ctrl+Entrée ou OKValide le texte
Échap ou AnnulerFerme l'éditeur sans modifier le texte
Ctrl+ASélectionne tout le texte

Dans la dernière ligne, vide, l'éditeur de texte ajoute une nouvelle ligne avec votre texte ; saisissez ensuite son symbole. L'éditeur conserve sa taille pour la fois suivante.

Trier

Outils › Trier trie les lignes par symbole, dans l'ordre dans lequel le fichier est enregistré : les majuscules viennent avant les minuscules, et les nombres contenus dans les symboles sont comparés selon leur valeur (item2 avant item10). Les lignes sans symbole sont placées à la fin.

Comme le fichier est toujours enregistré dans cet ordre, le tri ne compte pas comme une modification.

Importer

Outils › Importer... reprend les entrées d'une autre table de langue dont les symboles manquent dans la table active. Utilisez cette commande pour

  • commencer une nouvelle langue : créez une table vide et importez la table d'une langue existante, puis traduisez les textes ;
  • mettre une traduction à jour : importez la table de la langue d'origine pour obtenir toutes les entrées ajoutées depuis.

Les lignes importées sont ajoutées à la fin de la table avec les textes de l'autre table et sont sélectionnées, pour que vous voyiez ce qui est nouveau. Les lignes existantes et l'en-tête ne sont jamais modifiés. Si rien ne manque, l'éditeur vous l'indique.
