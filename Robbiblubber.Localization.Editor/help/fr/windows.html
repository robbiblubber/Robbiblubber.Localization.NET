Fichiers et fenêtres

Chaque fichier a sa propre fenêtre. Toutes les fenêtres appartiennent au même éditeur en cours d'exécution, partagent les menus et la liste des fichiers récents, et peuvent être disposées côte à côte.

Créer des fichiers

  • Fichier › Nouveau › Table (Ctrl+N) ouvre une nouvelle fenêtre avec une table de langue vide.
  • Fichier › Nouveau › Définition (Ctrl+Maj+N) ouvre une nouvelle fenêtre avec une définition de langue vide.

Ouvrir des fichiers

Fichier › Ouvrir... (Ctrl+O) ouvre un ou plusieurs fichiers ; vous pouvez en sélectionner plusieurs dans la boîte de dialogue. L'éditeur reconnaît les tables de langue et les définitions de langue à leur contenu, et non à leur nom de fichier.

  • Si la fenêtre active contient un nouveau document du même type, encore inchangé, le fichier le remplace ; sinon, une nouvelle fenêtre s'ouvre.
  • Si le fichier est déjà ouvert, sa fenêtre passe au premier plan et affiche le fichier tel qu'il est sur le disque. Si vous l'y avez modifié, l'éditeur vous demande d'abord s'il faut abandonner vos modifications.
  • Vous pouvez aussi ouvrir des fichiers en les passant à led.exe, par exemple en les faisant glisser dessus dans l'Explorateur ou en lançant led app.de.ltab dans une invite de commandes. Si l'éditeur est déjà en cours d'exécution, les fichiers s'ouvrent dans celui-ci.
  • Si un fichier contient plusieurs fois la même entrée, l'éditeur affiche un avertissement avec les symboles concernés. Seule la dernière valeur de chacun est affichée et enregistrée à nouveau.

Enregistrer

  • Fichier › Enregistrer (Ctrl+S) enregistre le fichier. Un nouveau fichier est enregistré avec Enregistrer sous.
  • Fichier › Enregistrer sous... (Ctrl+Maj+S) enregistre sous un nouveau nom. Pour les tables de langue, vous avez le choix entre une table normale (.ltab) et une table compressée (.cltab).
  • Avant d'enregistrer, l'éditeur vérifie le document et liste les éventuels problèmes, par exemple une langue manquante ou des symboles en double. Vous pouvez enregistrer quand même, ou annuler pour les corriger d'abord.
  • Un fichier ouvert dans une autre fenêtre ne peut pas être écrasé ; fermez-le d'abord dans cette fenêtre.

Modifications non enregistrées

Un * après le nom du fichier, dans la barre de titre et dans le menu Fenêtre, indique que le document contient des modifications non enregistrées. Si vous rétablissez l'état enregistré, le * disparaît. Lorsque vous fermez une fenêtre contenant des modifications non enregistrées, l'éditeur vous demande s'il faut les enregistrer.

Fermer

Fichier › Fermer (Ctrl+W) ferme la fenêtre active. L'éditeur se termine lorsque sa dernière fenêtre est fermée ; il n'y a pas de commande Quitter distincte.

Fichiers récents

Fichier › Fichiers récents liste les derniers fichiers que vous avez ouverts ou enregistrés, le plus récent en premier. Cliquez avec le bouton droit sur une entrée pour l'ouvrir, l'épingler ou la retirer de la liste ; Vider la liste supprime toutes les entrées non épinglées. Les fichiers épinglés restent en haut et ne disparaissent jamais de la liste. Si un fichier n'existe plus, l'éditeur propose de le retirer de la liste.

Le menu Fenêtre

Le menu Fenêtre liste toutes les fenêtres ouvertes. La fenêtre active est cochée ; sélectionnez-en une autre pour la faire passer au premier plan.

Position des fenêtres

L'éditeur mémorise la position et la taille de ses fenêtres, ainsi que la largeur des colonnes des tables. Les tables et les définitions de langue ont chacune leur propre position. Une nouvelle fenêtre ouverte depuis une fenêtre du même type est légèrement décalée, afin de ne pas recouvrir exactement l'autre.
