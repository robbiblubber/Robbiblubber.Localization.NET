Localization Editor

Localization Editor crée et modifie les fichiers qui permettent à une application de parler plusieurs langues : les tables de langue, qui contiennent les textes d'une langue, et les définitions de langue, qui décrivent une langue avec son nom et ses icônes.

Premiers pas

  1. Au démarrage, l'éditeur affiche une table de langue vide. Vous pouvez créer d'autres tables à tout moment avec Fichier › Nouveau › Table (Ctrl+N).
  2. Remplissez l'en-tête : indiquez la langue dans Langue (par exemple de) et les Préfixes utilisés par votre application (par exemple app).
  3. Saisissez un texte par ligne : le Symbole est le nom que votre application utilise pour ce texte (par exemple menu.file.open), le Texte est ce que voit l'utilisateur (par exemple &Öffnen...). Cliquez sur la dernière ligne, vide, pour ajouter une entrée.
  4. Enregistrez la table avec Fichier › Enregistrer (Ctrl+S). L'éditeur propose un nom de fichier tel que app.de.ltab.
  5. Pour une autre langue, créez une nouvelle table, indiquez sa langue et copiez-y toutes les entrées de la première table avec Outils › Importer.... Traduisez ensuite les textes ligne par ligne.

Appuyez sur F1 dans n'importe quelle fenêtre de l'éditeur pour ouvrir la page d'aide correspondante.

Types de fichiers

ExtensionContenu
.ltabTable de langue : les textes d'une langue, sous forme de texte lisible.
.cltabTable de langue compressée : le même contenu, mais plus compact et illisible en tant que texte.
.localeDéfinition de langue : clé, nom, langue de base et icônes d'une langue.
