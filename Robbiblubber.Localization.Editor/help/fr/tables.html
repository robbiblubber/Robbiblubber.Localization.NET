Tables de langue

La fenêtre d'une table de langue affiche l'en-tête de la table en haut et ses entrées en dessous. La barre d'état, en bas, indique le nombre d'entrées et de problèmes ainsi que le nom du fichier.

En-tête

ChampSignification
CléUn identifiant de la table, par exemple lt.app. Elle ne sert pas à rechercher les textes.
LangueLa clé de la langue à laquelle appartiennent les textes, par exemple de ou de-AT. Sans langue, la table n'est utilisée pour aucune langue.
NomUn nom descriptif, par exemple app.de.
VersionLa version de la table, par exemple 1.0.
PréfixesUn ou plusieurs préfixes, séparés par ; ou , (voir Notions de base). Les espaces sont ignorés.
AuteurLa personne qui a créé la table.

Entrées

Chaque ligne de la table est une entrée composée d'un Symbole et d'un Texte.

  • Ajouter : saisissez dans la dernière ligne, vide. Les lignes collées y sont également ajoutées (voir Édition et presse-papiers).
  • Modifier : sélectionnez une cellule et commencez à taper, appuyez sur F2 ou cliquez une nouvelle fois sur la cellule active. Appuyez sur Entrée pour valider la modification, sur Échap pour l'abandonner.
  • Textes longs : double-cliquez sur une cellule de texte ou appuyez sur Ctrl+E pour modifier le texte dans l'éditeur de texte.
  • Supprimer : sélectionnez des lignes entières en cliquant sur les en-têtes de ligne à gauche et appuyez sur Suppr.

L'ordre des lignes n'a pas d'importance. Le fichier est toujours enregistré trié par symbole ; Outils › Trier affiche les lignes dans cet ordre.

Sauts de ligne, tabulations et barres obliques inverses

La table affiche chaque texte sur une seule ligne. Les caractères spéciaux s'écrivent ainsi :

Dans la tableSignification
\nSaut de ligne
\tTabulation
\\Une barre oblique inverse, là où elle serait sinon lue comme \n ou \t, par exemple C:\\neu pour C:\neu.

Les autres barres obliques inverses restent telles quelles : C:\Data s'écrit simplement C:\Data. Dans l'éditeur de texte, en revanche, vous voyez et saisissez de vrais sauts de ligne et de vraies tabulations.

Problèmes

Les lignes qui présentent un problème reçoivent une marque rouge dans l'en-tête de ligne ; placez le pointeur dessus pour voir ce qui ne va pas. La barre d'état indique le nombre de ces lignes.

ProblèmeConséquence
Texte sans symboleLa ligne n'est pas enregistrée.
Symbole présent plusieurs foisSeule la dernière de ces lignes est enregistrée.
Symbole contenant un préfixe (:)La ligne est enregistrée, mais l'application chercherait app:app:.... Retirez le préfixe du symbole.

Lorsque vous enregistrez une table qui présente des problèmes, l'éditeur les liste et vous demande s'il faut enregistrer quand même. Il vous avertit également si le champ Langue est vide.

Enregistrer les tables

Pour une nouvelle table, l'éditeur propose un nom de fichier composé du premier préfixe et de la langue, par exemple app.de.ltab. Dans la boîte de dialogue Enregistrer, vous pouvez choisir Tables de langue compressées pour enregistrer plutôt un fichier .cltab.
