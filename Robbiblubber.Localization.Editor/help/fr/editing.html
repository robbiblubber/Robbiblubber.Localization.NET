Édition et presse-papiers

Les commandes du menu Édition fonctionnent où que vous soyez : dans un champ de l'en-tête, dans la table ou dans une cellule en cours de modification.

Commandes d'édition

CommandeRaccourciDans la table
AnnulerCtrl+ZUniquement pendant la modification d'une cellule.
CouperCtrl+XCopie les cellules sélectionnées et les vide.
CopierCtrl+CCopie les cellules sélectionnées.
CollerCtrl+VColle à partir de la cellule active.
SupprimerSupprVide les cellules sélectionnées ou supprime les lignes sélectionnées.
Tout sélectionnerCtrl+ASélectionne toutes les cellules.

Le menu n'active que les commandes possibles à ce moment-là, par exemple Coller uniquement si le presse-papiers contient quelque chose.

Copier et coller des cellules

  • Vous pouvez copier plusieurs cellules à la fois. Elles sont placées dans le presse-papiers sous forme de texte, avec des tabulations entre les colonnes et des sauts de ligne entre les lignes, ce qui permet de les coller dans Excel ou dans un éditeur de texte.
  • Les cellules copiées dans Excel peuvent être collées dans la table de la même manière. Le bloc collé commence à la cellule active.
  • Pour ajouter des entrées, copiez des lignes entières (sélectionnez les en-têtes de ligne), cliquez sur une cellule de la dernière ligne, vide, puis collez. Si vous collez plus de lignes qu'il n'y en a sous la cellule active, les lignes manquantes sont ajoutées.

Menus contextuels

Cliquez avec le bouton droit sur un champ de l'en-tête ou sur une cellule en cours de modification pour obtenir Annuler, Couper, Copier, Coller, Supprimer et Tout sélectionner pour ce champ. Cliquez avec le bouton droit sur la table pour obtenir les mêmes commandes pour les cellules sélectionnées, ainsi que l'Éditeur de texte.

Si vous cliquez avec le bouton droit sur une cellule située hors de la sélection, cette cellule est d'abord sélectionnée. Si vous cliquez avec le bouton droit dans une sélection, celle-ci est conservée, et la commande s'applique à toutes les cellules ou lignes sélectionnées.

Annuler

Les modifications de la table elle-même, comme le collage, la suppression de lignes ou Remplacer tout, ne peuvent pas encore être annulées. Annuler ne fonctionne que dans les champs de texte et pendant la modification d'une cellule. Si vous vous apprêtez à faire des modifications importantes, enregistrez d'abord le fichier : vous pourrez ainsi revenir en arrière en le rouvrant.
