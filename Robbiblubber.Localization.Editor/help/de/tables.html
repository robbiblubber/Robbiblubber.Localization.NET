Sprachtabellen

Das Fenster einer Sprachtabelle zeigt oben den Kopf der Tabelle und darunter ihre Einträge. Die Statusleiste unten zeigt die Anzahl der Einträge, Probleme und den Dateinamen.

Kopf

FeldBedeutung
SchlüsselEine Kennung der Tabelle, zum Beispiel lt.app. Zum Abrufen von Texten wird sie nicht verwendet.
SpracheDer Schlüssel der Sprache, zu der die Texte gehören, zum Beispiel de oder de-AT. Ohne Sprache wird die Tabelle für keine Sprache verwendet.
NameEin beschreibender Name, zum Beispiel app.de.
VersionDie Version der Tabelle, zum Beispiel 1.0.
PräfixeEin oder mehrere Präfixe, getrennt durch ; oder , (siehe Grundlagen). Leerzeichen werden ignoriert.
AutorWer die Tabelle erstellt hat.

Einträge

Jede Zeile der Tabelle ist ein Eintrag mit einem Symbol und einem Text.

  • Hinzufügen: Schreiben Sie in die leere letzte Zeile. Eingefügte Zeilen kommen ebenfalls dorthin (siehe Bearbeiten und Zwischenablage).
  • Bearbeiten: Wählen Sie eine Zelle und beginnen Sie zu tippen, drücken Sie F2 oder klicken Sie die aktuelle Zelle noch einmal an. Eingabe übernimmt die Änderung, Esc verwirft sie.
  • Lange Texte: Doppelklicken Sie auf eine Textzelle oder drücken Sie Strg+E, um den Text im Texteditor zu bearbeiten.
  • Löschen: Markieren Sie ganze Zeilen über die Zeilenköpfe links und drücken Sie Entf.

Die Reihenfolge der Zeilen spielt keine Rolle. Die Datei wird immer nach Symbol sortiert gespeichert; Extras › Sortieren zeigt die Zeilen in dieser Reihenfolge.

Zeilenumbrüche, Tabulatoren und umgekehrte Schrägstriche

Die Tabelle zeigt jeden Text in einer Zeile. Sonderzeichen werden so geschrieben:

In der TabelleBedeutung
\nZeilenumbruch
\tTabulator
\\Ein umgekehrter Schrägstrich, wo er sonst als \n oder \t gelesen würde, zum Beispiel C:\\neu für C:\neu.

Andere umgekehrte Schrägstriche bleiben, wie sie sind: C:\Daten ist einfach C:\Daten. Im Texteditor sehen und schreiben Sie stattdessen echte Zeilenumbrüche und Tabulatoren.

Probleme

Zeilen mit einem Problem bekommen im Zeilenkopf eine rote Markierung; zeigen Sie darauf, um zu sehen, was nicht stimmt. Die Statusleiste zeigt die Anzahl solcher Zeilen.

ProblemFolge
Text ohne SymbolDie Zeile wird nicht gespeichert.
Symbol kommt mehrfach vorNur die letzte dieser Zeilen wird gespeichert.
Symbol enthält ein Präfix (:)Die Zeile wird gespeichert, aber die Anwendung würde app:app:... suchen. Entfernen Sie das Präfix aus dem Symbol.

Speichern Sie eine Tabelle mit Problemen, listet der Editor sie auf und fragt, ob trotzdem gespeichert werden soll. Er warnt auch, wenn das Feld Sprache leer ist.

Tabellen speichern

Für eine neue Tabelle schlägt der Editor einen Dateinamen aus dem ersten Präfix und der Sprache vor, zum Beispiel app.de.ltab. Im Speichern-Dialog können Sie Komprimierte Sprachtabellen wählen, um stattdessen eine .cltab-Datei zu speichern.
