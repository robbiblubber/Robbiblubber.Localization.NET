Dateien und Fenster

Jede Datei hat ihr eigenes Fenster. Alle Fenster gehören zu einem laufenden Editor, teilen sich die Menüs und die Liste der zuletzt geöffneten Dateien und lassen sich nebeneinander anordnen.

Dateien anlegen

  • Datei › Neu › Tabelle (Strg+N) öffnet ein neues Fenster mit einer leeren Sprachtabelle.
  • Datei › Neu › Definition (Strg+Umschalt+N) öffnet ein neues Fenster mit einer leeren Sprachdefinition.

Dateien öffnen

Datei › Öffnen... (Strg+O) öffnet eine oder mehrere Dateien; im Dialog können Sie mehrere auswählen. Der Editor erkennt Sprachtabellen und Sprachdefinitionen an ihrem Inhalt, nicht am Dateinamen.

  • Enthält das aktuelle Fenster ein neues, unverändertes Dokument derselben Art, ersetzt die Datei es; sonst öffnet sich ein neues Fenster.
  • Ist die Datei schon geöffnet, kommt ihr Fenster nach vorn und zeigt die Datei so, wie sie auf dem Datenträger steht. Haben Sie sie dort geändert, fragt der Editor zuerst, ob Ihre Änderungen verworfen werden sollen.
  • Sie können Dateien auch öffnen, indem Sie sie an led.exe übergeben, zum Beispiel per Ziehen auf led.exe im Explorer oder mit led app.de.ltab in der Eingabeaufforderung. Läuft der Editor schon, öffnen sich die Dateien im laufenden Editor.
  • Enthält eine Datei denselben Eintrag mehrfach, zeigt der Editor eine Warnung mit den betroffenen Symbolen. Angezeigt und wieder gespeichert wird jeweils nur der letzte Wert.

Speichern

  • Datei › Speichern (Strg+S) speichert die Datei. Eine neue Datei wird mit Speichern unter gespeichert.
  • Datei › Speichern unter... (Strg+Umschalt+S) speichert unter einem neuen Namen. Bei Sprachtabellen können Sie zwischen einer normalen (.ltab) und einer komprimierten Tabelle (.cltab) wählen.
  • Vor dem Speichern prüft der Editor das Dokument und listet Probleme auf, zum Beispiel eine fehlende Sprache oder doppelte Symbole. Sie können trotzdem speichern oder abbrechen und die Probleme zuerst beheben.
  • Eine Datei, die in einem anderen Fenster geöffnet ist, kann nicht überschrieben werden; schließen Sie sie dort zuerst.

Ungespeicherte Änderungen

Ein * hinter dem Dateinamen in der Titelleiste und im Menü Fenster zeigt, dass das Dokument ungespeicherte Änderungen hat. Machen Sie eine Änderung rückgängig, sodass wieder der gespeicherte Stand erreicht ist, verschwindet der * wieder. Schließen Sie ein Fenster mit ungespeicherten Änderungen, fragt der Editor, ob sie gespeichert werden sollen.

Schließen

Datei › Schließen (Strg+W) schließt das aktuelle Fenster. Der Editor endet, wenn sein letztes Fenster geschlossen wird; einen eigenen Befehl zum Beenden gibt es nicht.

Zuletzt geöffnete Dateien

Datei › Zuletzt geöffnet listet die Dateien, die Sie zuletzt geöffnet oder gespeichert haben, die neueste zuerst. Mit einem Rechtsklick auf einen Eintrag können Sie ihn öffnen, anheften oder aus der Liste entfernen; Liste leeren entfernt alle Einträge, die nicht angeheftet sind. Angeheftete Dateien stehen oben und fallen nie aus der Liste. Gibt es eine Datei nicht mehr, bietet der Editor an, sie aus der Liste zu entfernen.

Das Menü Fenster

Das Menü Fenster listet alle offenen Fenster. Das aktuelle ist markiert; wählen Sie ein anderes, um es nach vorn zu holen.

Fensterpositionen

Der Editor merkt sich Position und Größe seiner Fenster sowie die Breite der Tabellenspalten. Tabellen und Sprachdefinitionen haben jeweils eine eigene Position. Ein neues Fenster, das aus einem Fenster derselben Art geöffnet wird, erscheint leicht versetzt, damit es das andere nicht genau verdeckt.
