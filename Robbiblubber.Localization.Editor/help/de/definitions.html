Sprachdefinitionen

Eine Sprachdefinition (.locale) beschreibt eine Sprache: ihren Schlüssel, ihren Namen, ihre Basissprache und die Icons, die bei der Auswahl einer Sprache angezeigt werden. Eine neue legen Sie mit Datei › Neu › Definition (Strg+Umschalt+N) an.

Felder

FeldBedeutung
SchlüsselDer kurze Schlüssel der Sprache, zum Beispiel de oder de-AT. Er darf keine Leerzeichen enthalten. Sprachtabellen verweisen über diesen Schlüssel auf die Sprache.
Basis-SchlüsselDer Schlüssel der Basissprache, zum Beispiel de für de-AT. Texte, die die Sprache nicht selbst enthält, kommen von dort. Wählen Sie einen aus der Liste oder geben Sie einen beliebigen Schlüssel ein; für eine Sprache ohne Basis lassen Sie das Feld leer.
NameDer Name, den der Benutzer sieht, meist in der Sprache selbst, zum Beispiel Deutsch. Ist er leer, wird der Schlüssel verwendet.
StandardspracheDie Anwendung verwendet diese Sprache, wenn keine andere gewählt wurde.
Rechts nach linksDie Sprache wird von rechts nach links geschrieben, zum Beispiel Arabisch oder Hebräisch.

Probleme wie ein Schlüssel mit Leerzeichen oder ein Basis-Schlüssel, der dem Schlüssel gleicht, zeigt die Statusleiste in Rot.

Icons

Eine Sprache hat ein Kleines Symbol mit 16 × 16 Pixeln für Listen und Menüs und ein Großes Symbol mit 32 × 32 Pixeln, das bei höherer Anzeigeskalierung verwendet wird. Neben jedem Icon steht seine tatsächliche Größe; ungewöhnliche Größen merkt der Editor an. Bilddateien werden unverändert gespeichert, eingefügte Bilder als PNG.

So setzen Sie ein Icon:

  • Doppelklicken Sie auf das Feld des Icons oder wählen Sie Laden... in seinem Kontextmenü und wählen Sie eine Bilddatei;
  • ziehen Sie eine Bilddatei aus dem Explorer auf das Feld; oder
  • klicken Sie auf das Feld und fügen Sie (Strg+V) ein Bild ein, das Sie in einem anderen Programm kopiert haben, oder eine im Explorer kopierte Bilddatei.

Ein ausgewähltes Icon-Feld unterstützt auch Kopieren, Ausschneiden und Löschen, über das Menü Bearbeiten, das Kontextmenü oder die Tastenkürzel. Kopieren Sie das kleine Icon und fügen Sie es in das große Feld ein, um für beide dasselbe Bild zu verwenden.

Speichern

Eine Definition lässt sich nur mit einem gültigen Schlüssel speichern. Fehlt ein Icon, warnt Sie der Editor: Ohne kleines Icon zeigt die Sprachauswahl einen Platzhalter, ohne großes wird das kleine verwendet. Für eine neue Definition schlägt der Editor <schlüssel>.locale als Dateinamen vor.

Eine Anwendung findet ihre Sprachen an denselben Stellen wie ihre Sprachtabellen. Um eine neue Sprache anzubieten, liefern Sie die .locale-Datei zusammen mit den Sprachtabellen dafür aus.
