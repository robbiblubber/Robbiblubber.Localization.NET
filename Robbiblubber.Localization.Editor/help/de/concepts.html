Grundlagen

Diese Seite erklärt, wie eine Anwendung ihre Texte findet und was das für die Dateien bedeutet, die Sie bearbeiten.

Sprachen

Eine Sprache (im Englischen „Locale“) kann auch für eine Region gelten. Jede Sprache hat einen kurzen Schlüssel, zum Beispiel en für Englisch, de für Deutsch oder de-AT für Deutsch in Österreich. Eine Sprachdefinition (.locale) beschreibt eine Sprache: ihren Schlüssel, den Namen, den der Benutzer sieht, ihre Icons und ein paar Einstellungen. Siehe Sprachdefinitionen.

Eine Sprache kann eine Basissprache haben. Eine Sprache de-AT mit der Basis de braucht nur die Texte, die in Österreich anders lauten; alle anderen Texte kommen aus de.

Sprachtabellen

Eine Sprachtabelle (.ltab oder .cltab) enthält die Texte einer Sprache für eine Anwendung oder einen Teil davon. Das Feld Sprache im Kopf der Tabelle gibt an, zu welcher Sprache die Texte gehören. Meist hat eine Anwendung eine Tabelle pro Sprache, zum Beispiel app.en.ltab, app.de.ltab und app.fr.ltab, jeweils mit denselben Symbolen.

Symbole und Texte

Jeder Eintrag einer Tabelle hat ein Symbol und einen Text. Das Symbol ist der Name, unter dem die Anwendung einen Text abruft; es ist in allen Sprachen gleich. Der Text ist die Übersetzung. Symbole bestehen meist aus Wörtern, die durch Punkte getrennt sind, zum Beispiel menu.file.open oder message.saved. Groß- und Kleinschreibung zählen: Save und save sind zwei verschiedene Symbole.

Präfixe

Das Präfix hält die Symbole verschiedener Anwendungen oder Komponenten auseinander. Die Anwendung fragt einen Text als präfix:symbol ab, zum Beispiel app:menu.file.open. In der Tabelle geben Sie nur das Symbol ein (menu.file.open) und das Präfix einmal im Kopf. Eine Tabelle mit mehreren Präfixen stellt ihre Symbole unter jedem davon bereit; eine Tabelle ohne Präfix stellt sie so bereit, wie sie sind.

Schreiben Sie das Präfix nicht vor die Symbole in der Tabelle. Der Editor markiert solche Zeilen als Problem, weil die Tabelle ihr Präfix ohnehin davorsetzt.

Platzhalter

Texte können Platzhalter enthalten: ein $ gefolgt von einem Namen in Großbuchstaben, zum Beispiel $NAME in $NAME wurde gespeichert. Die Anwendung ersetzt sie durch einen Wert. Lassen Sie Platzhalter beim Übersetzen unverändert; Sie dürfen sie aber an eine andere Stelle im Satz verschieben.

Zugriffstasten

In Texten für Menüs, Schaltflächen und Beschriftungen markiert ein & den Buchstaben, der unterstrichen wird und mit Alt ausgewählt werden kann, zum Beispiel &Öffnen.... Innerhalb eines Menüs oder Fensters sollte jeder Buchstabe nur einmal vorkommen. Für ein & selbst schreiben Sie &&.

Wenn ein Text fehlt

Enthält die Tabelle der aktuellen Sprache ein Symbol nicht, verwendet die Anwendung den Text der Basissprache oder einen in die Anwendung eingebauten Text, meist den englischen. Ein fehlender Eintrag führt also zu keinem Fehler, aber der Benutzer sieht einen nicht übersetzten Text.

Kommt dasselbe Symbol für dieselbe Sprache zweimal vor, gilt das spätere. Der Editor warnt Sie vor solchen doppelten Einträgen, sowohl in der Tabelle als auch beim Öffnen einer Datei.
