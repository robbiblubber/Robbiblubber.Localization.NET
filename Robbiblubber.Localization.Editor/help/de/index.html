Localization Editor

Der Localization Editor erstellt und bearbeitet die Dateien, mit denen eine Anwendung mehrere Sprachen spricht: Sprachtabellen mit den Texten einer Sprache und Sprachdefinitionen, die eine Sprache mit ihrem Namen und ihren Icons beschreiben.

Erste Schritte

  1. Beim Start zeigt der Editor eine leere Sprachtabelle. Weitere Tabellen legen Sie jederzeit mit Datei › Neu › Tabelle (Strg+N) an.
  2. Füllen Sie den Kopf aus: Tragen Sie unter Sprache die Sprache ein (zum Beispiel de) und unter Präfixe das Präfix, das Ihre Anwendung verwendet (zum Beispiel app).
  3. Geben Sie pro Zeile einen Text ein: Das Symbol ist der Name, unter dem Ihre Anwendung den Text abruft (zum Beispiel menu.file.open), der Text ist das, was der Benutzer sieht (zum Beispiel &Öffnen...). Klicken Sie in die leere letzte Zeile, um einen neuen Eintrag hinzuzufügen.
  4. Speichern Sie die Tabelle mit Datei › Speichern (Strg+S). Der Editor schlägt einen Dateinamen wie app.de.ltab vor.
  5. Für eine weitere Sprache legen Sie eine neue Tabelle an, setzen ihre Sprache und übernehmen alle Einträge der ersten Tabelle mit Extras › Importieren.... Danach übersetzen Sie die Texte Zeile für Zeile.

Drücken Sie in einem beliebigen Fenster des Editors F1, um die Hilfeseite zu diesem Fenster zu öffnen.
