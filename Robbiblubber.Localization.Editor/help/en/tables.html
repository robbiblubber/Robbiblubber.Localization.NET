Language tables

The window of a language table shows the header of the table at the top and its entries below. The status bar at the bottom shows the number of entries, problems and the file name.

Header

FieldMeaning
KeyAn identifier of the table, for example lt.app. It is not used to look up texts.
LocaleThe key of the locale the texts belong to, for example de or de-AT. Without a locale, the table is not used for any language.
NameA descriptive name, for example app.de.
VersionThe version of the table, for example 1.0.
PrefixesOne or more prefixes, separated by ; or , (see Basics). Blanks are ignored.
AuthorWho made the table.

Entries

Each row of the table is one entry with a Symbol and a Text.

  • Add: type into the empty last row. Pasted rows are added there as well (see Editing and clipboard).
  • Edit: select a cell and start typing, press F2, or click the current cell once more. Press Enter to take the change over, Esc to discard it.
  • Long texts: double-click a text cell or press Ctrl+E to edit the text in the text editor.
  • Delete: select whole rows by clicking the row headers at the left and press Del.

The order of the rows does not matter. The file is always saved sorted by symbol; Tools › Sort shows the rows in this order.

Line breaks, tabs and backslashes

The table shows every text in one line. Special characters are written like this:

In the tableMeaning
\nLine break
\tTab
\\A backslash, where it would otherwise be read as \n or \t, for example C:\\neu for C:\neu.

Other backslashes stay as they are: C:\Data is simply C:\Data. In the text editor you see and enter real line breaks and tabs instead.

Problems

Rows with a problem get a red mark in the row header; point at it to see what is wrong. The status bar shows the number of such rows.

ProblemWhat happens
Text without symbolThe row is not saved.
Symbol occurs more than onceOnly the last of these rows is saved.
Symbol contains a prefix (:)The row is saved, but the application would look for app:app:.... Remove the prefix from the symbol.

When you save a table with problems, the editor lists them and asks whether to save anyway. It also warns you if the Locale field is empty.

Saving tables

For a new table, the editor suggests a file name made of the first prefix and the locale, for example app.de.ltab. In the Save dialog you can choose Compressed Language Tables to save a .cltab file instead.
