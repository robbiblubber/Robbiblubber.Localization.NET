Find and replace

The Find window searches the symbols and texts of the active language table and replaces them if you want.

Opening the Find window

  • Edit › Find... (Ctrl+F) opens the window for searching.
  • Edit › Replace... (Ctrl+H) opens it with the additional field Replace with. In the window, Ctrl+F and Ctrl+H switch between the two.
  • If a cell is selected, its text is suggested as search text; while you are editing a cell, the selected part of it.

The window stays in front of the editor windows and always works on the table window that was active last. Locale definitions cannot be searched. Esc closes the window; it keeps its texts, options and position for the next time.

Options

OptionEffect
Look inSearches the Symbol column, the Text column or Both. With both, the symbol of a row is searched before its text.
Match caseDistinguishes upper and lower case.
Match whole wordOnly finds the search text if it is not part of a longer word.
Regular expressionsReads the search text as a regular expression (see below).
Search backwardsSearches towards the beginning of the table.

Finding

Find Next (or Enter) selects the next cell that contains the search text. At the end of the table, the search continues at the beginning; the window says so in its status bar. If nothing is found, you hear a beep.

Texts are searched as the table shows them, so \n finds line breaks.

You do not need to keep the window open: Edit › Find Next (F3) and Shift+F3 search forwards and backwards with the last search text and options. The result appears in the status bar of the table window.

Replacing

  • Replace first finds the next cell. Pressed again, it replaces all occurrences in that cell and finds the next one, so you can check every cell before you replace.
  • Replace All tells you how many occurrences in how many rows it will replace and asks before it does so.

Replacing cannot be undone. Save the table before you replace a lot.

Regular expressions

With Regular expressions, the search text is a .NET regular expression. Some examples:

Find whatFinds
^menu\.Symbols that begin with menu.
\.\.\.$Texts that end with ...
\$[A-Z]+Placeholders such as $NAME
^$Empty cells

In Replace with, $1, $2 and so on insert the parts of the match in parentheses. For example, ^menu\.(\w+)$ replaced by main.$1 turns menu.file into main.file. Without regular expressions, $1 is inserted as it is.

If the expression is not valid, the window says why. A search that takes too long is cancelled.

History

The Find what and Replace with lists offer the last 10 texts you used, and the options are kept as well, also after a restart.
