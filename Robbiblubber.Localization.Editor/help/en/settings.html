Settings

Tools › Settings... (Ctrl+Alt+S) opens the settings of the editor.

Language of the editor

Under Environment › Languages, choose the User Interface Language. All windows switch at once, so you can see the result right away. OK keeps the new language; Cancel or Esc returns to the previous one. The editor remembers your choice.

The editor comes with English, Deutsch, Français and Bahasa Indonesia.

Adding a language to the editor

The editor is localized with its own files, so you can translate it yourself:

  1. Create a locale definition for the language, for example es.locale.
  2. Open the English table of the editor, led.en.ltab in the folder locale next to led.exe, save it as led.es.ltab, set its Locale to es and translate the texts.
  3. Put both files into the folder locale next to led.exe and restart the editor.

The new language then appears in the settings. Texts that are missing in your table are shown in English.

Appearance

Under Environment › Appearance, choose the Theme of the editor. Like the language, the theme changes all windows at once; OK keeps it, Cancel returns to the previous one.

ThemeColors
AutomaticLight or dark, as set for apps in the Windows settings; with high contrast, the Windows colors
SystemThe Windows colors, as without a theme
LightLight colors
DarkDark colors

Your own themes follow the built-in themes in the list.

Your own themes

The link Customize... next to the list opens the theme editor. Create a theme with New or Copy. Every theme is Based on another theme and only changes the colors you set: select a color and click Change...; Reset color takes the color of the base theme again. The preview shows the result right away. Import... and Export... exchange themes as .theme files, Remove deletes a theme. The built-in themes cannot be changed.

When you close the theme editor with OK, the theme selected there becomes the theme of the editor, and your themes are saved at once, even if you close the settings with Cancel afterwards.

Your themes are kept in %APPDATA%\robbiblubber\themes. Other applications of robbiblubber.org that support themes use the same folder, so a theme you create here is available there too, and the other way round. Each application keeps its own choice of theme.

Stored settings

The editor keeps its settings for each user in %LOCALAPPDATA%\robbiblubber.org\led:

FileContent
led.settingsLanguage of the editor, search history and search options
led.recentThe list of recent files
led.layoutPositions and sizes of the windows and widths of the table columns
led.themesThe theme of the editor

If a window opens in an unexpected place, close the editor and delete led.layout. All windows then open at their default positions again.
