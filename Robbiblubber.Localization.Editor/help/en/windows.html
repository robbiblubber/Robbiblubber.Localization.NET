Files and windows

Every file has its own window. All windows belong to one running editor, share the menus and the list of recent files, and can be arranged side by side.

Creating files

  • File › New › Table (Ctrl+N) opens a new window with an empty language table.
  • File › New › Definition (Ctrl+Shift+N) opens a new window with an empty locale definition.

Opening files

File › Open... (Ctrl+O) opens one or more files; you can select several in the dialog. The editor recognizes language tables and locale definitions by their content, not by their file name.

  • If the current window contains a new, unchanged document of the same kind, the file replaces it; otherwise a new window opens.
  • If the file is already open, its window comes to the front and shows the file as it is on disk. If you have changed it there, the editor first asks whether to discard your changes.
  • You can also open files by passing them to led.exe, for example by dragging them onto it in Explorer or by starting led app.de.ltab in a command prompt. If the editor is already running, the files open in the running editor.
  • If a file contains the same entry more than once, the editor shows a warning with the affected symbols. Only the last value of each is shown and saved again.

Saving

  • File › Save (Ctrl+S) saves the file. A new file is saved with Save As.
  • File › Save As... (Ctrl+Shift+S) saves under a new name. For language tables you can choose between a normal (.ltab) and a compressed table (.cltab).
  • Before saving, the editor checks the document and lists any problems, for example a missing locale or duplicate symbols. You can save anyway or cancel and correct them first.
  • A file that is open in another window cannot be saved over; close it there first.

Unsaved changes

A * after the file name in the title bar and in the Window menu shows that the document has unsaved changes. If you change something back to the saved state, the * disappears again. When you close a window with unsaved changes, the editor asks whether to save them.

Closing

File › Close (Ctrl+W) closes the current window. The editor ends when its last window is closed; there is no separate Exit command.

Recent files

File › Recent Files lists the last files you opened or saved, the most recent first. Right-click an entry to open it, pin it or remove it from the list; Clear List removes all entries that are not pinned. Pinned files stay at the top and never drop out of the list. If a file no longer exists, the editor offers to remove it from the list.

The Window menu

The Window menu lists all open windows. The current one is checked; select another to bring it to the front.

Window positions

The editor remembers the position and size of its windows, and the width of the table columns. Tables and locale definitions each have their own position. A new window opened from a window of the same kind is placed slightly offset, so it does not cover the other one exactly.
