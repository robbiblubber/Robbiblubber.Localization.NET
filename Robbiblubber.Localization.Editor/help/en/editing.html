Editing and clipboard

The commands of the Edit menu work wherever you are: in a header field, in the table or in a cell you are editing.

Edit commands

CommandShortcutIn the table
UndoCtrl+ZOnly while editing a cell.
CutCtrl+XCopies the selected cells and clears them.
CopyCtrl+CCopies the selected cells.
PasteCtrl+VPastes from the current cell on.
DeleteDelClears the selected cells, or removes the selected rows.
Select AllCtrl+ASelects all cells.

The menu only enables the commands that are possible at the moment, for example Paste only if there is something on the clipboard.

Copying and pasting cells

  • You can copy several cells at once. They are put on the clipboard as text with tabs between the columns and line breaks between the rows, so you can paste them into Excel or a text editor.
  • Cells copied in Excel can be pasted into the table the same way. The pasted block starts at the current cell.
  • To add entries, copy whole rows (select the row headers), click a cell of the empty last row and paste. If you paste more rows than there are below the current cell, the missing rows are added.

Context menus

Right-click a header field or a cell you are editing to get Undo, Cut, Copy, Paste, Delete and Select All for that field. Right-click the table to get the same commands for the selected cells, and the Text Editor.

If you right-click a cell outside the selection, that cell is selected first. If you right-click inside a selection, the selection stays, so the command applies to all selected cells or rows.

Undo

Changes to the table itself, such as pasting, deleting rows or Replace All, cannot be undone yet. Undo only works in text fields and while you are editing a cell. If you are about to make large changes, save the file first, so you can go back by opening it again.
