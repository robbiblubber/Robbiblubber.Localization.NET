Tools

The Tools menu helps with long texts and with keeping several tables in step. The tools are available in language table windows.

Text editor

The text editor shows a text with real line breaks and tabs, which makes longer texts easier to read and write. Open it with:

  • Tools › Text Editor... or Ctrl+E,
  • a double-click on a text cell, or
  • Text Editor... in the context menu of the table.

The editor always edits the text of the current row, also if the symbol cell is selected; its title shows the symbol.

KeyEffect
EnterNew line
TabTab
Ctrl+Enter or OKTakes the text over
Esc or CancelCloses the editor without changing the text
Ctrl+ASelects the whole text

In the empty last row, the text editor adds a new row with your text; enter its symbol afterwards. The editor keeps its size for the next time.

Sort

Tools › Sort sorts the rows by symbol, in the order in which the file is saved: capital letters come before small letters, and numbers within symbols are compared by value (item2 before item10). Rows without symbol go to the end.

Since the file is always saved in this order, sorting does not count as a change.

Import

Tools › Import... takes over the entries of another language table whose symbols are missing in the current table. Use it to

  • start a new language: create an empty table and import the table of an existing language, then translate the texts;
  • bring a translation up to date: import the table of the original language to get all entries that have been added since.

Imported rows are added at the end of the table with the texts of the other table and are selected, so you can see what is new. Existing rows and the header are never changed. If nothing is missing, the editor tells you so.
