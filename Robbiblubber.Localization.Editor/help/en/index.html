Localization Editor

The Localization Editor creates and edits the files that let an application speak several languages: language tables with the texts of one language, and locale definitions that describe a language with its name and icons.

First steps

  1. When the editor starts, it shows an empty language table. You can create further tables at any time with File › New › Table (Ctrl+N).
  2. Fill in the header: enter the language in Locale (for example de) and the Prefixes your application uses (for example app).
  3. Enter one text per row: the Symbol is the name your application uses for the text (for example menu.file.open), the Text is what the user sees (for example &Öffnen...). Click the empty last row to add a new entry.
  4. Save the table with File › Save (Ctrl+S). The editor suggests a file name such as app.de.ltab.
  5. For a further language, create a new table, set its locale and copy all entries of the first table into it with Tools › Import.... Then translate the texts row by row.

Press F1 in any window of the editor to open the help page that belongs to it.

File types

ExtensionContent
.ltabLanguage table: the texts of one language, as readable text.
.cltabCompressed language table: the same content, but smaller and not readable as text.
.localeLocale definition: key, name, base locale and icons of a language.
