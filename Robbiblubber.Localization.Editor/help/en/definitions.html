Locale definitions

A locale definition (.locale) describes a language: its key, its name, its base locale and the icons shown when the user chooses a language. Create one with File › New › Definition (Ctrl+Shift+N).

Fields

FieldMeaning
KeyThe short key of the locale, for example de or de-AT. It must not contain blanks. Language tables refer to the locale by this key.
Base keyThe key of the base locale, for example de for de-AT. Texts the locale does not define are taken from there. Choose one from the list or type any key; leave it empty for a locale without base.
NameThe name shown to the user, usually in the language itself, for example Deutsch. If it is empty, the key is used.
Default localeThe application uses this locale if no other has been chosen.
Right to leftThe language is written from right to left, for example Arabic or Hebrew.

Problems such as a key with blanks or a base key equal to the key are shown in red in the status bar.

Icons

A locale has a Small icon of 16 × 16 pixels, shown in lists and menus, and a Large icon of 32 × 32 pixels, used at higher display scaling. Next to each icon you see its real size; the editor points out unusual sizes. Image files are saved unchanged; pasted images are stored as PNG.

To set an icon:

  • double-click the icon box or choose Load... in its context menu and select an image file;
  • drag an image file from Explorer onto the box; or
  • click the box and paste (Ctrl+V) an image copied in another program, or an image file copied in Explorer.

A selected icon box also supports Copy, Cut and Delete, through the Edit menu, the context menu or the shortcuts. Copy the small icon and paste it into the large box to use the same picture for both.

Saving

A definition can only be saved with a valid key. If an icon is missing, the editor warns you: without small icon, the language selection shows a placeholder; without large icon, the small one is used instead. For a new definition, the editor suggests <key>.locale as file name.

An application finds its locales in the same places as its language tables. To offer a new language, provide the .locale file together with the language tables for it.
